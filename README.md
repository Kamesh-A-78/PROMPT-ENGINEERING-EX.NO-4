Use Case: AI-Based Smart Manufacturing Automation System
Scenario

The manufacturing industry aims to reduce manual monitoring and improve operational efficiency using automation technologies. IoT devices and embedded systems are used to automate equipment, monitor machine performance, and support predictive maintenance. This helps industries improve productivity, reduce downtime, and save energy.

The target audience includes manufacturing companies in automotive, electronics, and food processing sectors where automation plays an important role in improving efficiency.

The main objectives are to improve production efficiency by 30%, minimize machinery downtime, enable real-time monitoring, and reduce energy consumption through optimized industrial processes.

1. Comparative Analysis Prompt
Prompt

“Compare AI-based predictive maintenance and traditional manual maintenance methods in manufacturing industries. Explain the differences in cost, efficiency, downtime reduction, and monitoring capabilities.”

This prompt is designed to compare two different maintenance approaches used in industries. The AI explains how traditional maintenance depends heavily on manual inspection, while AI-based predictive maintenance uses sensors and machine learning algorithms to detect issues before failures occur. The comparison includes advantages, disadvantages, costs, efficiency, and monitoring capabilities.

When tested with different AI tools, OpenAI provided highly detailed and structured explanations with clear comparisons. Google generated concise and informative responses, while xAI produced simpler and more conversational answers.

The evaluation was based on clarity, technical accuracy, comparison quality, and relevance of the generated content. ChatGPT performed better in providing comprehensive and technically accurate responses.

2. Experiential Perspective Prompt
Prompt

“As a factory manager, describe your experience using AI-powered automation systems for monitoring manufacturing equipment and reducing downtime.”

This prompt focuses on generating responses from a personal or professional perspective. The AI responds as if it were a factory manager explaining real-world experiences with automation systems. The generated content includes benefits such as improved monitoring, reduced downtime, increased efficiency, and easier maintenance scheduling.

Among the AI tools tested, OpenAI created more realistic and human-like responses. Google provided well-organized explanations, while xAI generated shorter and less detailed responses.

The evaluation considered creativity, realism, clarity, and relevance. ChatGPT showed better performance in producing natural and engaging experiential content.
3. Everyday Functioning Prompt
Prompt

“Explain how AI and IoT are used in everyday manufacturing operations such as machine monitoring, temperature sensing, and automated quality checking.”

This prompt helps explain how AI technologies are used in regular industrial activities. The AI describes applications like smart sensors for temperature monitoring, automated quality inspection systems, and machine performance tracking in simple language.

OpenAI generated clear explanations with practical examples that were easy to understand. Google produced informative responses with good structure, while xAI gave shorter outputs with fewer technical details.

The evaluation was based on simplicity, practical examples, technical correctness, and user understanding. ChatGPT achieved better results due to its detailed and beginner-friendly explanations.
4. Universal Prompt Structures
Prompt

“Explain the working process of an AI-based smart manufacturing system step by step with a simple example.”

This prompt follows a universal structure where the AI explains a concept in a step-by-step manner. The generated response describes stages such as data collection from sensors, data processing, machine monitoring, predictive analysis, and automated control systems.

When compared, OpenAI provided the most detailed and systematic explanation. Google generated structured responses with moderate detail, while xAI gave simpler explanations with limited depth.

The evaluation focused on structure, clarity, completeness, and quality of examples. ChatGPT performed best because of its organized and comprehensive responses.

5. Prompt Size Limitations
Prompt

“Explain 100 AI applications used in smart manufacturing industries with examples.”

Large prompts sometimes create incomplete or overly long responses. To improve efficiency, the prompt was refined into a smaller and more manageable version.

Refined Prompt

“Explain 10 AI applications used in smart manufacturing industries with examples.”

The refined prompt helped the AI generate more focused and accurate outputs. The response became easier to understand and avoided missing important details.

Among the tools tested, OpenAI handled prompt refinement effectively and maintained response quality. Google also managed large prompts reasonably well, while xAI sometimes shortened responses due to prompt size limitations.

The evaluation was based on efficiency, information coverage, response accuracy, and prompt optimization. ChatGPT demonstrated better capability in handling refined prompts and generating meaningful content.
